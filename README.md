# Personal Homepage

This is a lightweight GitHub Pages-ready personal homepage.

## Files

- `index.html`: main homepage content.
- `assets/styles.css`: visual styling and responsive layout.
- `assets/main.js`: section navigation highlighting and footer year behavior.
- `assets/smile.png`: profile image used on the homepage.
- `assets/finreporting-system.png`: teaser image for the FinReporting selected publication.
- `assets/Fan.pdf`: CV linked from the profile panel.
